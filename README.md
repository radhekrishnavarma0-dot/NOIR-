# NOIRÉ — The Art of Scent

A fictional luxury perfume e-commerce website, built as a portfolio demo by **Houseofpri**.

**Live demo:** https://your-username.github.io/repo-name/

> NOIRÉ is not a real brand. All products, prices, discounts and testimonials are illustrative. Nothing can be bought, and no payment or personal data is collected.

## Features
- Cinematic hero with a curved arch layout
- 8 demo fragrances with notes, demo INR prices and MRP
- Collection filters (Dark, Floral, Fresh) and search
- Quick View modal with quantity selector
- Shopping bag drawer: add, change quantity, remove, live subtotal
- Demo-only checkout screen (checkout is disabled)
- Scent Finder: pick a mood and get a matching fragrance
- Newsletter form with email validation (nothing is stored or sent)
- Privacy Policy, Terms and Security pages
- Fully responsive, keyboard accessible, respects reduced-motion

## Tech
Plain HTML, CSS and JavaScript in a single `index.html`. No frameworks, no build step, no backend. Fonts: Cormorant Garamond and Inter (Google Fonts).

## Run locally
Download `index.html` and open it in any browser.

## Deploy
Settings → Pages → Deploy from a branch → `main` / root.

## Privacy
The shopping bag is saved only in your browser (localStorage). No cookies, no analytics, nothing is sent to a server.
